Quick Actions, as four folders

This is idea 4 from the five, made taller and built to grow. Each folder shows four actions as direct buttons. Today every folder has exactly four, so there’s nothing hidden and no count to read. When a folder grows past four, a small “5 more” link appears under it and the card stays the same size, so modules can be added without redesigning the panel. The panel is live, and the switcher below takes it through each state.

Show Actions

Three ways to reach any action

  1. 1tap

    Tap a shortcut on the folder

    Each folder shows four actions. Today that’s all sixteen, so for now this is the whole panel.

  2. 2taps

    Open the folder

    Once a folder has more than four, tap its name or “5 more”. The panel slides to a full list, grouped under small headings, with a line under each action saying what it records. Back returns you to the folders.

  3. Aatype

    Type in the field

    Searches every folder at once and shows which folder each result is in. If no action matches, one button takes the same words to Search everything.

Choosing the shortcuts

  • Star any action inside a folder and it becomes one of that folder’s shortcuts, replacing the one you use least. A folder shows at most four.
  • Nothing starred yet? The shortcuts come from your role: a vet sees Medical Record, Dispense and Vaccination, and a keeper sees Transfer, Eggs and Report Missing.
  • Drafts are one strip at the top, “4 to finish”, and it’s hidden when there are none. A shortcut with a draft behind it shows a small Draft tag.

When a new module arrives

  • The folder card doesn’t get taller. A “5 more” link appears under the four rows, and a “5 new” tag sits beside the folder name.
  • New actions go under the right heading inside the folder, marked New for 14 days.
  • A new heading inside a folder is fine. A fifth folder is only added when a whole area arrives that fits none of the four.
